# Estate Community App - React Native

A comprehensive React Native application built with **Expo** for managing community/estate operations. Features include resident management, financial tracking, announcements, events, and maintenance requests.

## 🎯 Core Features

### Dashboard
- Real-time financial overview (collected funds, expenses, balance)
- Payment status metrics (paid, partial, unpaid residents)
- Quick access to upcoming events
- Recent activity timeline

### Residents Management
- Complete resident directory with contact information
- Payment status tracking (paid, unpaid, partial, overdue)
- Outstanding dues calculation
- Search and filter by name, house number, and street
- Detailed resident profiles with transaction history

### Financial Management
- Transaction history tracking (credits and debits)
- Categorized transactions (Dues, Projects, Events, Maintenance, Emergency)
- Financial summary and reporting
- Payment status updates

### Announcements & News
- Priority-based announcements (critical, high, medium, low)
- View counts and engagement metrics
- Category filtering and search
- Full announcement details with author information

### Event Management
- Upcoming and past events
- Event status tracking (upcoming, ongoing, completed, cancelled)
- Attendance count and budget management
- Event location and countdown timer

### Maintenance Requests
- Request creation and tracking
- Priority levels (low, medium, high, urgent)
- Status management (open, assigned, in-progress, completed, cancelled)
- Cost estimation and tracking
- Image attachments support
- Category-based organization

## 📱 Tech Stack

- **Framework**: React Native 0.81.5
- **Build Tool**: Expo 54
- **Navigation**: Expo Router
- **State Management**: Zustand
- **Data Fetching**: React Query (@tanstack/react-query)
- **Icons**: Lucide React Native
- **Language**: TypeScript
- **Date Handling**: date-fns
